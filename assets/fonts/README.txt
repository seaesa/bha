Chép file font Comic Sans bản Việt hoá (SVN hoặc VNF) vào thư mục này, đặt đúng tên:

  SVN-ComicSansMS.ttf        (chữ thường)
  SVN-ComicSansMS-Bold.ttf   (chữ đậm, nếu có)

Có thể dùng .woff2 cùng tên (nhẹ hơn): SVN-ComicSansMS.woff2, SVN-ComicSansMS-Bold.woff2

Không cần sửa code — style.css đã khai báo sẵn (@font-face "Racons Comic").
Máy nào đã cài sẵn SVN/VNF Comic Sans MS sẽ dùng font trên máy, không cần tải file.
